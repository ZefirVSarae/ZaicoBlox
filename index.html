Справочник API

Управление блоками
spawn(type, x, y) Создает блок. Типы: "grass", "dirt", "spike", "trigger".
delete(id) Удаляет блок по его уникальному ID.
move_to(id, x, y) Телепортирует блок на указанные координаты x и y.
move_by(id, dx, dy) Сдвигает блок на dx по горизонтали и dy по вертикали.
set_color(id, hexColor) Меняет цвет блока. Пример цвета: "#ff0000".
get_x(id) / get_y(id) Возвращает текущую координату X или Y блока.
get_type(id) Возвращает тип блока в виде строки.
Управление игроком
player_jump(power) Заставляет игрока подпрыгнуть. Чем выше число, тем сильнее.
player_kill() Убивает игрока и отправляет на точку спавна.
player_set_pos(x, y) Мгновенно перемещает игрока на новые координаты.
player_get_x() / player_get_y() Возвращает координаты игрока.
set_speed(speed) Устанавливает максимальную скорость бега (по умолчанию 6).
set_gravity(grav) Устанавливает силу гравитации (по умолчанию 0.6).
События (Писать в коде)
function OnStart() Вызывается один раз при нажатии кнопки "Играть".
function OnTick() Вызывается каждый кадр игры. Осторожно с тяжелым кодом.
function OnTouch(id) Вызывается, когда игрок касается любого физического блока.
function OnTrigger(id) Вызывается, когда игрок касается блока типа "trigger".
function OnDeath() Вызывается в момент смерти игрока (падение или шипы).
Прочее
print("текст") Выводит сообщение в игровую консоль справа.
Система: Консоль готова
