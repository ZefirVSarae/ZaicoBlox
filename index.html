Скрипт

Справочник API

Ожидание
wait(sec) Приостанавливает выполнение скрипта на sec секунд.
GUI
create_text(name, text, x, y, size, color) Создает текст на экране.
create_frame(name, x, y, w, h, color) Создает фон/блок интерфейса.
create_button(name, text, x, y, w, h, color) Создает кликабельную кнопку.
update_text(name, text, x, y, size, color) Обновляет параметры текста.
update_frame(name, x, y, w, h, color) Обновляет параметры фрейма/кнопки.
set_visible(name, visible) Скрывает или показывает элемент (true/false).
delete_text(name) / delete_frame(name) Удаляет элемент GUI с экрана.
function OnGuiClick(name) Событие: вызывается при клике по кнопке.
События игры
function OnStart() Вызывается 1 раз при старте.
function OnTick() Вызывается каждый кадр.
function OnTouch(id) Касание физ. блока.
function OnTrigger(id) Касание trigger-блока.
function OnDeath() Смерть игрока.
Управление блоками
spawn(type, x, y) Создает блок. Типы: "grass", "dirt", "spike", "trigger".
delete(id) Удаляет блок по ID.
move_to(id, x, y) / move_by(id, dx, dy) Движение блоков.
set_color(id, hexColor) Меняет цвет. Пример: "#ff0000".
get_x(id) / get_y(id) / get_type(id) Инфо о блоке.
Управление игроком
player_jump(power) Прыжок.
player_kill() Убивает игрока.
player_set_pos(x, y) Телепорт.
player_get_x() / player_get_y() Координаты игрока.
set_speed(speed) / set_gravity(grav) Физика игрока.
print("текст") Пишет в консоль.
Луа готов! Для команд смотри справочник.
